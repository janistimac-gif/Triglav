# Triglav

Slovenski spletni brskalnik (Electron).

## Zagon

```bash
npm install
npm start
```

## Windows namestitev

```bat
install.bat
```

Ustvari `dist/Triglav-Setup-*.exe`.

## Funkcije

- Zavihki, zaznamki, zgodovina
- Temno / svetlo / sistemsko ozadje
- Blokada sledilnikov, lazy-load slik
- Prednalaganje zaznamkov, disk cache
- Uvoz zaznamkov iz Chrome / Firefox / Edge
